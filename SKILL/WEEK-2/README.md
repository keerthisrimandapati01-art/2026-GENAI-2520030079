# GEN AI – WEEK 2

## 🤖 Provider-Agnostic LLM Client

### 📌 Description
This project implements a **provider-agnostic Large Language Model (LLM) client** that provides a common interface to interact with different AI models.

The project integrates:

- **Google Gemini** – A hosted cloud-based LLM.
- **Ollama (Llama 3.2)** – A locally running LLM.

### 🛠️ Technologies Used
- Python
- Google Gemini API
- Ollama
- Llama 3.2
- Google Colab

### ✨ Features
- Common interface for multiple LLM providers.
- Generate responses using Gemini and Ollama.
- Switch between providers easily.
- Reusable and modular code.

### 🎯 Objective
To understand how multiple LLM providers can be integrated through a single interface without changing the main application logic.

### ▶️ Execution
Run the **Google Colab notebook** from top to bottom.
